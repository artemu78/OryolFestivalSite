# Фестиваль ментального здоровья в Орле

## Что это

Одностраничный сайт первого Фестиваля ментального здоровья в Орле. Приложение на React и Vite, без сервера и базы данных. Контент на русском языке. Публикация — GitHub Pages.

Фестиваль: 10 октября 2026 года, 11:30–18:30, закрытие в 18:30. Площадка: коворкинг Freedom, Орёл, наб. Дубровинского, 60Б. Все 35 билетов проданы.

## Цель

Достойно представить камерный фестиваль и дать его участникам программу, знакомство с ведущими и сведения о площадке. Сайт также служит реальным кейсом Студии Артёма Рева для привлечения клиентов на создание сайтов и чатботов.

Не добавлять продажу билетов, регистрацию на фестиваль, личные кабинеты или другую сложность без запроса. Предварительная запись на отдельные практики — условие участия из программы, а не доступная на сайте система бронирования.

## Блоки страницы

1. **Шапка** — название фестиваля, навигация, ссылка на сообщество VK; на телефоне раскрывающееся меню.
2. **Первый экран** — «Ближе к себе», дата и время, описание и переход к программе. Фон на всю ширину и высоту окна: заставка (`public/girls/1001.png` на десктопе, `public/girls/1001-mobile.png` на мобильных) до фактического старта видео, затем зацикленное беззвучное видео (`gemini_generated_video_4ba23423.mp4` на десктопе, портретное `gemini_generated_video_mobile.mp4` на экранах до 700 px). Есть пауза; при ошибке остаётся картинка.
3. **Краткие сведения** — дата, время, Freedom, адрес и 35 участников.
4. **О фестивале (`#about`)** — уважение, принятие, понятные разговоры и бережные практики.
5. **Программа (`#program`)** — события по порядку из JSON, фильтры категорий, время, описание, зал и условия записи. У ведущих — портреты и ссылки VK. После 14:30 часть событий идёт параллельно.
6. **Эксперты (`#experts`)** — фотографии, профессиональные описания и ссылки на профили всех ведущих из общего реестра.
7. **Живые голоса (`#videos`)** — место для будущих видеознакомств и ссылка на сообщество. Ролики экспертов пока не добавлены.
8. **Место встречи (`#location`)** — адрес, время, ссылки площадки и встроенная карта. `.address` располагает сведения и карту рядом на компьютере, друг под другом при ширине до 800 px.
9. **Завершение** — приглашение быть собой и сообщение, что все места заняты.
10. **Подвал** — фестиваль, VK и точная подпись «Сайт — Студия Артёма Рева». Контакт студии пока не предоставлен; не придумывать ссылку.

## Где менять содержимое

- `src/main.jsx` и `src/components/` — структура страницы и интерактивные элементы.
- `src/site.json` — тексты разделов, кнопок, сообщений интерфейса, метаданные и сведения площадки.
- `src/experts.json` — имена, фотографии, профили и описания экспертов.
- `src/styles.css` — оформление и адаптивность.
- `src/program.json` — редактируемая программа. Поля: `time`, `category`, `tag`, `title`, `text`, необязательные `location`, `access`, `people`. Порядок элементов определяет порядок событий; категории фильтров берутся из данных.
- `src/program.js` — сведения площадки и связь имён ведущих из JSON с реестром экспертов.
- `src/experts.js` — общий реестр на основе `src/experts.json`. Имена в `people` должны точно совпадать с реестром. Неизвестное имя вызывает ошибку.
- `public/girls/` — портреты, заставка и фоновое видео. Названия портретов соответствуют фамилиям; точное сопоставление — в реестре.
- `docs/editing-programme.md` — инструкция по редактированию JSON.
- `docs/expert-sources.md` — источники описаний и ограничения доступа к профилям.
- `docs/prototype.md` — согласованные цели и исходные сведения.
- `docs/github-pages.md` — настройка публикации.
- `CONTEXT.md` — словарь проекта, без деталей реализации.

## Правила изменений

- Сохранять мобильную адаптацию, молочный фон, глубокий зелёный, крупную типографику и спокойное настроение.
- Сохранять пользовательские изменения; не смешивать задачу с посторонним рефакторингом.
- Не выдумывать квалификацию, биографии, контакты или свободные места. Профили Кордычко и Аксёновой скрыты; текущие описания основаны на предоставленной программе.
- Татьяна Хотеева исключена по прямой просьбе пользователя. Не возвращать её из старых исходных материалов без нового указания.
- Новые статические ссылки на файлы формировать с `import.meta.env.BASE_URL`, чтобы сайт работал под путём репозитория GitHub Pages.
- У интерактивных элементов сохранять клавиатурную доступность, видимый фокус и понятные названия.
- Для вопросов о библиотеках, SDK, API, CLI и облачных сервисах использовать Context7: сначала `resolve-library-id`, затем `query-docs` по конкретной теме. Это не требуется для простого рефакторинга, изменений контента и общей бизнес-логики.

## Проверка и публикация

```sh
npm ci
npm run dev
npm run build
```

Для проверки пути GitHub Pages:

```sh
PAGES_BASE_PATH=/OryolFestivalSite/ npm run build
PAGES_BASE_PATH=/OryolFestivalSite/ npm run preview
```

После изменений проверять сборку и `git diff --check`; для визуальных изменений — подходящий экран на компьютере и телефоне. Для программы проверять соответствие имён реестру и наличие фотографий. Отдельного тестового набора сейчас нет.

`.github/workflows/pages.yml` публикует `dist` после push в `main` или ручного запуска. Путь сайта передаётся через `PAGES_BASE_PATH` из настроек Pages. Репозиторий: `artemu78/OryolFestivalSite`.

`npm run build` создаёт локальную сборку; опубликованный сайт обновляется только после отправки изменений и успешного workflow. Коммитить и отправлять изменения, когда это входит в запрос пользователя.
