# Редактирование текстов сайта

- `src/site.json` — тексты всех разделов, навигации, кнопок и сообщений интерфейса. Ключи разделов соответствуют компонентам страницы. `metadata` содержит заголовок вкладки и описание для поисковых систем; `venue` — сведения площадки; `links` — ссылку на сообщество фестиваля.
- `src/experts.json` — общий реестр имён, профессиональных описаний, фотографий и профилей экспертов. Он используется и в карточках экспертов, и в программе. Имена должны точно совпадать с `people` в `src/program.json`.
- `src/program.json` — тексты активностей и расписание; см. [инструкцию по программе](editing-programme.md).

Поля `titleLead`, `titleEmphasis`, `subtitleSecond` и подобные разделяют текст там, где в оформлении предусмотрены перенос строки или курсив. Сохраняйте пробелы в начале и конце строк, если они отделяют соседние части текста. В `Experts.profileLabel` оставляйте `{name}`: вместо него подставляется имя эксперта.

JSON использует двойные кавычки и не допускает комментарии. Не добавляйте HTML в строки: оформление задают компоненты страницы.

После изменения выполните сборку. Заголовок и описание из `metadata` подставляются в HTML при запуске или сборке сайта. Если меняете их при работающем сервере разработки, перезапустите сервер. Для публикации отправьте изменения в `main` и дождитесь успешного workflow GitHub Pages.
