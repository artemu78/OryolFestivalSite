# Редактирование программы

Все события находятся в `src/program.json`, в порядке отображения на сайте.

Источник истины для событий с 12:10 — [эталон программы](programme-reference.md). При изменении времени сверяйте начало и конец каждого события с ним. Визуальные блоки объединяют только события с полностью одинаковым диапазоном `time`: кабинеты 14:30–17:30 нельзя объединять под общим временем с часовыми круглыми столами. События до 12:10 в этом эталоне не описаны.

- `time` — время или диапазон времени.
- `category` — раздел фильтра; существующие: «Встреча», «Разговоры», «Практики». Новые категории появляются автоматически.
- `tag` — короткая подпись над названием.
- `title` — название события.
- `text` — описание.
- `location` — зал; необязательное поле.
- `access` — условия участия; необязательное поле.
- `people` — список полных имён ведущих; необязательное поле. Имена должны точно совпадать с `name` в `src/experts.json`, откуда берутся фотографии и ссылки. Неизвестное имя вызывает явную ошибку.

Добавлять, удалять и переставлять события можно прямо в JSON. Строки пишутся в двойных кавычках; комментарии и запятая после последнего элемента не допускаются.

При запущенном `npm run dev` изменения появятся автоматически. Для опубликованного сайта отправьте изменения в `main` и дождитесь workflow GitHub Pages.
