# Публичные профили экспертов

После миграции источник профилей — таблицы `Users` и `ExpertProfiles` в YDB.
Администратор редактирует профили в админке. Изменения станут видимыми посетителям
после операторского экспорта, сборки и публикации обоих путей размещения.

`src/experts.json` — проверяемый публичный снимок. Экспорт включает только `id`,
`name`, `photo`, `profile`, `role` (публичная профессия) и `text`. Числовые VK ID,
заметки, права, посещаемость и ключи доступа не экспортируются. Скрипт читает
только ID/имена пользователей и публичные поля профилей в одной транзакции.
Порядок: `sort_order`, затем ID. Сборка работает без доступа к облаку.

## Операторский экспорт

Установите зависимости из `infra/yandex/admin/requirements.txt` в отдельном
Python-окружении. Задайте `YDB_ENDPOINT`, `YDB_DATABASE` и
`YC_SERVICE_ACCOUNT_KEY_FILE` из существующей локальной настройки. Не добавляйте
значения переменных, ключи и состояние Terraform в Git или клиентский код.

```sh
python infra/yandex/export-public-experts.py
npm run build
PAGES_BASE_PATH=/OryolFestivalSite/ npm run build
git diff --check
```

Экспорт сначала проверяет все ссылки `people` из программы и существование
портретов, затем атомарно заменяет файл. Если ведущий удалён из базы, но остался
в программе, экспорт завершается ошибкой и сохраняет предыдущий снимок.
Фотографии должны уже находиться в `public/`; загрузка файлов не добавлена.
Стабильный ID эксперта равен внутреннему ID пользователя. Переименование не
требует правки программы. ID событий 1–15 остаются отдельными числовыми ID.

Проверьте публичный diff и отправьте снимок в Git вместе с необходимыми правками
программы. GitHub Pages публикуется workflow после push; Yandex Cloud требует
отдельной корневой сборки и загрузки по `infra/yandex/README.md`.

## Начальный снимок до миграции

Первый снимок был получен **из утверждённого исходного контента**.
5 октября 2026 года таблицы развёрнуты; перед публикацией выполнен обычный
экспорт 13 профилей из живой YDB. `infra/yandex/experts-seed.json` — неизменяемый публичный seed
для миграции; Татьяна Хотеева исключена согласно AGENTS.md. Он не содержит
приватных данных. `--bootstrap` воспроизводит этот снимок без облачных ключей:

```sh
python infra/yandex/export-public-experts.py --bootstrap
```

После cutover обязательно выполните обычный экспорт из живой YDB **до публикации**.
Не используйте bootstrap после начала редактирования в админке: он отменит
изменения публичного снимка. Миграция всегда читает seed, а не будущие снимки.

Проверки: `npm run validate:public` и
`python -m unittest discover -s infra/yandex -p 'test_public_export.py'`.
Публичная валидация выполняется также перед каждой сборкой.
