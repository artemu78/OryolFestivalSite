# Прототип фестиваля

Согласованная цель: достойно представить камерный фестиваль для участников с купленными билетами. Прототип будет показан организатору, а после согласования может стать кейсом Студии Артёма Рева для привлечения клиентов.

## Согласовано

- Одностраничное React-приложение, в первую очередь для телефона.
- Молочный фон, глубокий зелёный, крупная типографика, мягкие формы.
- О фестивале, анонсированные события, эксперты, место для видеознакомств.
- Все 35 билетов проданы; регистрация и продажа не нужны.
- Подпись: «Сайт — Студия Артёма Рева».

## Источники и незаполненные данные

Факты о фестивале и экспертные роли взяты из постов ВКонтакте, предоставленных пользователем в приложенном тексте. Город, дата и число участников подтверждены этим текстом; коворкинг указан пользователем. Живую страницу ВКонтакте не проверяли.

«Ближе к себе» — предложенный заголовок страницы, не официальное название мероприятия. Ботаническая иллюстрация и карточки с инициалами — оформление прототипа, не фотографии экспертов.

Не подтверждены точный адрес, время начала фестиваля, полная программа и время выступления Оксаны Воронцовой. Не выдумывать их при дальнейших правках. Известное начало танцевальной практики — 17:30.

Видео не выбраны. Текущий блок ведёт в сообщество, не изображает готовый видеоплеер. Перед добавлением роликов согласовать материалы с организатором.

Ссылка студии ещё не предоставлена. Добавить её в `studioContact` в `src/main.jsx`; до этого подпись остаётся текстом.

## Запуск

`npm install`, затем `npm run dev`. Сборка: `npm run build`. Локальная проверка сборки: `npm run preview`.
