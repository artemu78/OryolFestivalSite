# Подготовка изображений

Исходные изображения остаются в `public/girls/`, `public/activity-backgrounds/`
и `public/logos/`. Можно заменить или добавить файл с обычным именем: менять
пути в YDB для оптимизации не нужно. Оригиналы не перезаписываются.

`npm run build` и `npm run dev` автоматически запускают `npm run images:optimize`.
Sharp создаёт WebP-копии в `public/optimized-images/` и карту вариантов
`manifest.json`. Каталог не коммитится: он воспроизводится при сборке, в том
числе в GitHub Actions. Нужна обычная установка зависимостей через `npm ci`.
После замены исходников во время разработки перезапустите `npm run dev`.

| Назначение | Максимальный размер | Качество WebP |
| --- | --- | --- |
| Аватар ведущего в программе | 160 × 160 | 80 |
| Карточка эксперта | 640 × 960 | 84 |
| Фон события | 1280 × 1280 | 78 |
| Логотип спонсора | 800 × 800 | 86 |
| Логотип в шапке | 320 × 320 | 88 |

Размеры — ограничивающая рамка: пропорции сохраняются, изображения не
растягиваются и не кадрируются. Для скриншота «Браф» рамка 800 × 1600,
а прежнее кадрирование остаётся в CSS. Прозрачность сохраняется, EXIF-ориентация
применяется до уменьшения. Если WebP оказался больше исходника, используется
исходник. SVG, видео, анимации и отдельные заставки `1001*` не преобразуются.

`src/imageUrl.js` выбирает копию по роли, затем использует общий `assetUrl`
для базового пути и версии. Внешние HTTP(S)-картинки не скачиваются и не
преобразуются. Если локальный путь ещё не попал в сборку, сохраняется исходный
URL. Добавленным после публикации файлам нужна новая сборка для оптимизации.

Имена WebP содержат хеш содержимого, поэтому обновления не застревают в кеше.
Предзагрузка логотипа и картинка в шапке используют один и тот же вариант.
Исходники остаются доступными по прежним URL, но компоненты сайта загружают
подходящие уменьшенные копии. Настройки SSG этот этап не меняет; при прямом
вызове Vite вместо `npm run build` сначала выполните `npm run images:optimize`.

Проверка генератора и совместимости URL:

```sh
node --test scripts/optimize-images.test.mjs scripts/cache.test.mjs
```
